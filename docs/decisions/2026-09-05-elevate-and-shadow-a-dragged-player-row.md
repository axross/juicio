# Elevate and Shadow a Dragged Player Row

A player row lifted off the stack by long-press-to-drag scales up slightly
and casts a drop shadow while held, both released on drop. The design file
draws no drag affordance for this row at all, so both whether to show a
lift and how to show one were open, presented as a three-option exhibit and
resolved by choosing this option — "elevate and shadow" — over the other
two.

Scaling the row up and adding a shadow reads as the row physically lifting
off the stack, the closest of the three options to a native iOS/Android
drag-and-drop affordance a user is likely to already recognize. Both
effects release back to their resting values on drop, so the lifted state
reads as a temporary condition of the drag itself, not a permanent change to
the row.

The other two options the exhibit presented, and the reasoning that ranked
this one above them, are not restated here — this record exists to name the
option this project actually built and why it reads as elevation, not to
reconstruct an exhibit this record cannot independently verify the full
content of.
